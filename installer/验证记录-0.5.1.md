## 验证边界

本机实际宿主只有 Rhino 8.35。Rhino 8.0–8.34 的兼容依据是 8.0 SDK 编译、运行时策略及 .NET 7 验证；尚未在 Rhino 8.0 原版宿主上执行实机验收。早期版本正式推广前仍需外部试装，特别是材质显示与 WebView2 初始化。

Rhino 8.0–8.6 没有 TreatAsLinear 属性，使用宿主材质通道默认值；8.7+ 保留原有显式标记。当前不覆盖 Rhino 7 / 9、macOS 或 .NET Framework 模式。安装包尚未代码签名。

官方依据：[Rhino .NET 运行时说明](https://www.rhino3d.com/en/docs/guides/netcore/)；[RhinoCommon 迁移指南](https://developer.rhino3d.com/guides/rhinocommon/moving-to-dotnet-core/)；[TreatAsLinear 引入版本](https://mcneel.github.io/rhinocommon-api-docs/api/RhinoCommon/html/P_Rhino_DocObjects_Texture_TreatAsLinear.htm)。
