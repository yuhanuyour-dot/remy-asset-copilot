Remy Asset Copilot 0.5.4 Beta - Windows installer

Requirements
Windows 10/11 x64 and Rhino 8.0 or a later Rhino 8.x release.
Compatible with Rhino's .NET Framework, .NET 7, and .NET 8 modes.
The Rhino 8.0 SDK is the API baseline. Testing on the original Rhino 8.0 host
and an independent clean Windows machine is still pending. macOS is not supported.

Install and open
1. Save your work and close all Rhino windows.
2. Run the installer and confirm the detected Rhino.exe.
3. Choose the program and data folders. Any supported local drive can be used.
4. For image-based size estimation, use Full and select Offline image size estimates.
5. Open Rhino normally, create or open a document, type AssetCopilot, and press Enter.
   The command has no spaces. No separate launcher or runtime change is required.

Installer choices
Full: Standard plus the optional offline image-based size estimation model.
Standard: Plugin, GLB decoder, PBR preview, generation, and other sizing methods.
Update: For an existing 0.5.0 or newer universal installation only. It does not
include Node.js or the image recognition model. Use Standard or Full to install
for the first time, repair missing runtime files, or migrate from 0.4.x.
Upgrading an existing Full installation with Standard preserves image recognition.
Setup does not automatically download extra components.

Using Remy
- Type a description, drop a JPG/PNG image into the preview, add one with +, or paste with Ctrl+V.
- Use + > Add GLB model to preview and place an existing GLB without API credits.
- Open Connection & task recovery to enter your Tripo API key. It is used only
  in the current window. Online generation requires your own API credits.
- Image plus text can use two billable stages: image editing and 3D generation.
- Size & scale offers Manual, Real-world, and Reference modes. Real-world sizes
  are estimates based on image/text recognition and size rules, not measurements
  from a photograph. Reference uses a planar face selected in Rhino.
- Use the upper-right chevron to switch between full and compact windows.
- Change the model save folder under Model & texture storage.
- User descriptions, filenames, document names, and saved assets retain their
  original content. Both English and Chinese size descriptions remain supported.

Data and upgrades
Default program: %LOCALAPPDATA%\Programs\RemyAssetCopilot
Default data: %LOCALAPPDATA%\RemyAssetCopilot\Data
These folders can be changed during installation. Upgrades retain the existing
DataRoot, models, textures, settings, and task records. Keep the same program
folder when upgrading. Shortcuts do not install updates; run the new installer.
Only one Remy plugin location is registered per Windows user. Uninstall an old
universal installation before intentionally moving the program to a new folder.

Uninstall
Close Rhino, then open Windows Settings > Apps > Remy Asset Copilot > Uninstall.
Uninstall removes program files and the current installation's registration.
Models, textures, settings, and working data are retained. Back up your data
before removing it manually.

Troubleshooting
- Rhino is already open: type AssetCopilot in its command line. Do not repeatedly
  drag the RHP into Rhino.
- Plugin file or runtime missing: run Standard or Full again to repair it.
- Image size recognition unavailable: run Full and select its optional component.
  Text-based size estimation and Manual size remain available.
- Preview requires the Microsoft Edge WebView2 Runtime used by Rhino. If it fails,
  generation progress stays visible. Click Retry preview when idle to rebuild the
  preview without submitting another task. Diagnostics: data folder/work/preview-errors.log.
- The plugin does not change Rhino's global runtime preference.
- API errors: use Check connection for a read-only authentication check. If a
  generation submission is unconfirmed, find its task ID in the Tripo dashboard
  and resume checking rather than submitting again.

This is an unsigned beta installer. Windows or your browser may display a
reputation warning. Verify the release source and SHA256SUMS before installing.
Do not upload API keys, personal models, settings.json, or task records to GitHub.
Third-party licenses are included in AssetCopilot/THIRD-PARTY-NOTICES.md and
